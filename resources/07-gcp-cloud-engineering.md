# GCP Cloud Engineering (Associate Cloud Engineer → Professional Cloud Architect)

Entry-level cloud engineering, then advanced architecture. Do this before the Data Engineer cert if GCP is new to you.

## Prep Path (in order)
1. **Google Cloud Skills Boost: Cloud Engineer path** — https://www.cloudskillsboost.google/paths/9
   Official training, free credits included.
2. **Coursera: Preparing for the Associate Cloud Engineer** — https://www.coursera.org/learn/preparing-cloud-associate-cloud-engineer-certification-exam
   Plus Google Cloud Fundamentals on Coursera: https://www.coursera.org/professional-certificates/google-cloud-fundamentals-aws
3. **Qwiklabs hands-on labs** — https://www.cloudskillsboost.google/catalog
   The exam is hands-on heavy; courses alone won't pass it.
4. **Mock exams** — Whizlabs: https://www.whizlabs.com/google-cloud-certification-exams/associate-cloud-engineer/ · ExamPro: https://www.exampro.co/gcp
5. Free credits via Skills Boost — build real projects

## What the Exam Tests
- Compute: Compute Engine VM, GKE, Cloud Run
- Networking: VPC, load balancers, Cloud DNS
- Storage: Cloud Storage, Cloud SQL
- IAM, billing, cost management
- Deployment: Cloud Build, Terraform (IaC)
- Hands-on troubleshooting (no pure recall questions)

## After Associate: Professional Cloud Architect (optional)
- **Official cert page** — https://cloud.google.com/learn/certification/cloud-architect
- Advanced: HA architecture, security, migration, cost/performance optimization
- Best combined with DDIA concepts from system design

## Milestone
Deploy a service on Cloud Run with IaC (Terraform), a VPC + load balancer, and Cloud Storage lifecycle rules — entirely from Skills Boost labs and free credits.
