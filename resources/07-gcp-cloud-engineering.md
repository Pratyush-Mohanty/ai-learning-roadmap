# GCP Cloud Engineering (Associate Cloud Engineer → Professional Cloud Architect)

Entry-level cloud engineering, then advanced architecture. Do this before the Data Engineer cert if GCP is new to you.

## Prep path (in order)
1. **Google Cloud Skills Boost: Cloud Engineer path** — official, free credits included
2. **Coursera: Preparing for Associate Cloud Engineer** + Google Cloud Fundamentals
3. **Qwiklabs hands-on labs** — the exam is hands-on heavy; courses alone won't pass it
4. Mock exams: Whizlabs, ExamPro
5. Free credits via Skills Boost — build real projects

## What the exam tests
- Compute (VM, GKE, Cloud Run), networking (VPC, load balancers), storage (GCS, Cloud SQL)
- IAM, billing, cost management
- Deployment: Cloud Build, Terraform, IaC basics
- Hands-on troubleshooting (no pure recall questions)

## After Associate: Professional Cloud Architect (optional)
- More advanced: HA architecture, security, migration, cost/performance optimization
- Best combined with DDIA concepts from system design

## Milestone
Deploy a service on Cloud Run with IaC (Terraform), a VPC + load balancer, and GCS lifecycle rules — entirely from Skills Boost labs and free credits.
