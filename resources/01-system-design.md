# System Design

For a data engineer, start with DDIA (your background makes this a fast read), use the Primer as a reference, and practice designs out loud.

## Books (in order)
1. **Designing Data-Intensive Applications** (Kleppmann) — https://www.oreilly.com/library/view/designing-data-intensive-applications/9781098119058/
   Distributed systems bible: replication, partitioning, consistency, stream processing. Highest leverage for you.
2. **System Design Interview Vol 1 & 2** (Alex Xu) — https://www.amazon.com/System-Design-Interview-Second-Insiders/dp/B08CMF2CQF
   Interview framework + 20+ worked designs (URL shortener, chat, rate limiter, etc.)
3. **Machine Learning Systems** (Chip Huyen) — https://www.oreilly.com/library/view/machine-learning-systems/9781098106812/
   Production ML lifecycle, monitoring, drift (bridge to AI engineering)

## GitHub (use as reference, not cover-to-cover)
- **System Design Primer** — https://github.com/donnemartin/system-design-primer
  Concepts, diagrams, Anki flashcards, practice problems. The most-starred system design repo.
- **System Design (karanpratapsingh)** — https://github.com/karanpratapsingh/system-design
  Structured, course-style walkthrough. Best linear path.
- **Awesome System Design Resources** — https://github.com/ashishps1/awesome-system-design-resources
  Curated concepts + interview problems, actively maintained.
- **Grokking System Design** — https://github.com/design-gurus/grokking-system-design
  Official pattern-based companion to the Grokking course.
- **System Design Resources (InterviewReady)** — https://github.com/InterviewReady/system-design-resources
  Curated interview links + real company examples.
- **Engineering Blogs** — https://github.com/kilimchoi/engineering-blogs
  Real company architecture writeups (Uber, Netflix, Airbnb).

## ML System Design (your bridge topic)

## Practice (do this part)
- 10-12 core designs: URL shortener, rate limiter, chat system, news feed, search, key-value store, web crawler, notification system, ride-sharing, video streaming, payment system, distributed ID generator
- Record yourself explaining each design out loud
- Use Excalidraw (https://excalidraw.com) for diagrams in practice
