# System Design

For a data engineer, start with DDIA (your background makes this a fast read), use the Primer as a reference, and practice designs out loud.

## Books (in order)
1. **Designing Data-Intensive Applications** (Kleppmann) — distributed systems bible; replication, partitioning, consistency, stream processing. Highest leverage for you.
2. **System Design Interview Vol 1 & 2** (Alex Xu) — interview framework + 20+ worked designs
3. **Machine Learning Systems** (Chip Huyen) — production ML lifecycle, monitoring, drift (bridge to AI engineering)
