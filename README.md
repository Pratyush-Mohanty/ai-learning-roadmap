## Who this is for

- 4 years of data engineering experience (SQL, pipelines, warehousing already assumed)

## Philosophy

- **One resource, one home.** Cross-links instead of duplication.
- **Learn → Build → Ship.** Every phase ends with a hands-on project.
- **Most leverage first.** Prioritize techniques with the highest impact (e.g., continuous batching = 23x, vs micro-optimizations).
